# Docker-инструменты системного аналитика — старт

**Для личного ПК с Docker Desktop:** [[17 - Быстрый старт на локальном ПК]] — Ubuntu, Windows и macOS, доступ через `127.0.0.1`. **Для уже установленного локального Kubernetes:** [[18 - Быстрый старт в локальном Kubernetes]]. Серверный сценарий Ubuntu/LAN описан ниже и в [[02 - Установка и первый запуск]].

> [!abstract] Что это
> Готовое **Obsidian-хранилище (Markdown + конфигурации)** для локального развёртывания портала инструментов, Portainer, Mermaid Live Editor, Kroki, PlantUML Server, Swagger Editor, Swagger UI, draw.io, Next AI Draw.io и AsyncAPI Studio. Docker Engine и Docker Compose **уже установлены**.

**Единая стартовая страница:** `http://192.168.88.42:18080` — карточки всех инструментов, поиск и категории. Адреса формируются из `.env` при запуске; см. [[15 - Портал инструментов]].

> [!important] Параметры по умолчанию
> Ubuntu 24.04, IP `192.168.88.42`, доступ из доверенной локальной сети. Это **настройка-пример**: прежде чем запускать, проверьте адрес через `ip -4 -brief address` и укажите свой `BIND_IP` в `.env`. В интернете без VPN/TLS и ограничения доступа сервисы не публиковать.

| Путь | Назначение |

| `compose.yaml` | Основной Compose-проект: портал, редакторы, Kroki и 2–3 companion-контейнера; Portainer отдельно. |

| `.env.example` | IP и порты, пример для `.env`. |

| `scripts/prepare-drawio-ai.py` | Автоматически создаёт локальные настройки штатного AI и прокси из `.env`. |

| `scripts/healthcheck.sh` | Проверяет все HTTP-сервисы и POST API Kroki. |
| `scripts/update.sh` | Обновление готовых Docker-образов (Mermaid обновляется отдельно). |
| `scripts/backup-config.sh` | Резервное копирование Compose, скриптов, спецификаций и примеров. |

| `samples/` | Рабочие примеры Mermaid, PlantUML, OpenAPI/AsyncAPI. |
| `assets/portainer/` | **Локальные обучающие иллюстрации**, доступны офлайн. |

## Самый короткий путь

```bash
# После распаковки архива на Ubuntu:
cd /путь/к/SA-Docker-Obsidian
cp .env.example .env
nano .env                # проверьте BIND_IP, порты и подключение AI; либо отключите DRAWIO_AI_ENABLED
bash scripts/first-run.sh
bash scripts/healthcheck.sh
```

**Portainer**, если отсутствует, запускается отдельной командой — см. [[02 - Установка и первый запуск]].

> [!warning] Если ранее уже запускали набор на портах 18081–18087
> Сначала проверьте старые контейнеры и остановите **только старый** Compose-проект, иначе порты будут заняты. `docker compose down` выполняйте только в каталоге старого проекта, который действительно хотите остановить.
