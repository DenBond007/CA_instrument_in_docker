# Начало

Откройте **[[00 - Старт]]** — навигация по 15 подробным инструкциям, скриптам и конфигурациям.

Обязательно проверьте `BIND_IP` в `.env` перед запуском. `bash scripts/first-run.sh` скачивает готовые образы, включая кастомный Mermaid из GHCR. Адрес Kroki передаётся при запуске контейнера; пересборка при смене IP не нужна.

Исходники проекта: https://github.com/DenBond007/CA_instrument_in_docker

Публичный образ: `ghcr.io/denbond007/mermaid-live-editor-runtime:1.0.0` (AMD64 и ARM64). Скачивание доступно без авторизации и токенов; подробности в **[[03 - Mermaid и локальный Kroki]]**.

Отдельная памятка: **[[09 - Portainer - инструкция со скриншотами]]**.
