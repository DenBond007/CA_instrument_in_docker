# Начало

Откройте **[[00 - Старт]]** — навигация по 19 подробным заметкам, скриптам и конфигурациям.

**Быстрый запуск на личном ПК:** [[17 - Быстрый старт на локальном ПК]] — Ubuntu, Windows (Docker Desktop + WSL 2) и macOS, адрес `http://127.0.0.1:18080`, первый запуск без LLM. Если установлен Kubernetes: [[18 - Быстрый старт в локальном Kubernetes]] — готовые локальные манифесты и один `port-forward` для всех инструментов.

**Стартовая страница инструментов:** `http://<BIND_IP>:18080`. Карточки Mermaid, PlantUML, draw.io, Swagger, AsyncAPI, Kroki и Portainer собраны в одном месте; работают поиск по названию/задаче, категории и светлая/тёмная тема. Подробности и настройки — **[[15 - Портал инструментов]]**.

**AI-схемы:** Next AI Draw.io добавлен на `http://<BIND_IP>:18088` с подключением локальной LLM, DeepSeek или OpenAI-совместимого API; см. **[[16 - Next AI Draw.io]]**. На текущем ПК подключён локальный Unsloth. Новая карточка портала требует локальной сборки из обновлённых исходников; опубликованный портал `1.0.0` её ещё не содержит.

**Штатный AI обычного draw.io готов к работе на `18085`**: `first-run.sh` автоматически создаёт локальные настройки и запускает прокси к модели. Ключ остаётся на сервере, вводить его в браузере не нужно. Пример `.env` выбирает локальную сборку актуального портала. Настройка, запуск и использование — **[[08 - draw.io]]**.

![Стартовая страница инструментов](assets/portal/desktop.png)

Обязательно проверьте `BIND_IP` в `.env` перед запуском. `bash scripts/first-run.sh` скачивает готовые образы, включая кастомный Mermaid из GHCR. Адрес Kroki передаётся при запуске контейнера; пересборка при смене IP не нужна.

Исходники проекта: https://github.com/DenBond007/CA_instrument_in_docker

Публичные образы (AMD64 и ARM64):

- Портал: `ghcr.io/denbond007/analyst-portal:1.0.0`.
- Mermaid: `ghcr.io/denbond007/mermaid-live-editor-runtime:1.0.0`.

Скачивание доступно без авторизации и токенов; подробности в **[[15 - Портал инструментов]]** и **[[03 - Mermaid и локальный Kroki]]**.

Отдельная памятка: **[[09 - Portainer - инструкция со скриншотами]]**.
